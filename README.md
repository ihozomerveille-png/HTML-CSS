# Explore Kigali

A multi-page website showcasing things to do and places to eat around Kigali, Rwanda.

## Project Description

This website was built as an HTML and CSS assignment. It provides visitors with useful information about popular destinations in Kigali — including historical sites, local markets, and top restaurants. The site is structured across five HTML pages, each styled with its own CSS file.

## HTML Pages

| File | Description |
|------|-------------|
| `index.html` | Home page — overview of Kigali with navigation to all destination pages |
| `memorial.html` | Kigali Genocide Memorial — history, visitor info, map, and media |
| `market.html` | Kimironko Market — shopping guide, tips, and market details |
| `heaven.html` | Heaven Restaurant — menu highlights, dining info, and location |
| `repub.html` | Repub Lounge — nightlife, live music, food, and atmosphere |

## What This Project Demonstrates

- Proper HTML5 page structure using semantic elements (`header`, `nav`, `main`, `section`, `footer`, `figure`)
- Use of a wide range of HTML tags: headings, paragraphs, lists, tables, images, video, audio, iframe, links, figcaption
- Internal navigation between pages and external links to real websites
- Ordered and unordered lists on every page
- Tables with `thead` and `tbody` for structured information
- Embedded Google Maps via `<iframe>` on every page
- `<video>` and `<audio>` elements with `<source>` tags
- Separate CSS file per page with unique color themes
- CSS classes, multiple selectors, and image styling (size, border, border-radius, object-fit)
- Responsive layout using flexbox
